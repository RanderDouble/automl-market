# 机制改进设计与讲稿（1 分钟）

## 我们发现了什么

复现过程中我们发现论文机制存在三个层面的问题：

**第一，强制购买不现实。** 论文 MILP 假设买家必须买，但真实市场可以不买。实验显示：加入退出选项后，论文最优价格的实际收入反而不如简单独立定价——说明优化的目标和真实收入之间是错位的。

**第二，冷启动矛盾。** 定价需要已知买家分布，分布又需要多轮交易学到——第一轮价格凭什么最优？论文没有处理这个"先有鸡还是先有蛋"的问题。

**第三，搜索成本被忽略。** Theorem 4.2 假设每轮搜索成本 $c\approx0$。但成本不为零时，买家会更早停止、看到更少选项，最优价格应该与搜索成本耦合，而不是独立决定。

**第四，定价与发现过程脱节。** 论文把"发现什么数据增强"和"怎么定价"当作两个独立模块。但发现引擎的质量分布直接影响买家能买到什么——平台应该根据定价目标引导发现方向。

## 已实现的改进

对应四个改进：

1. **外部选项修正**：把退出权利写进买家响应评估，用来审计论文 forced-choice 目标和真实可退出市场之间的差距。
2. **有限场景鲁棒定价**：在一组手工先验/成本场景上最大化最坏收入；这不是完整 Wasserstein/KL DRO。
3. **成本感知定价**：解除 $c\approx0$ 假设，用精确 Markov 停止响应评估搜索成本非零时的收入，让价格随成本自适应。
4. **warm-start 定价引导发现**：把来自历史交易或元数据的价格信号反馈给 Data-Bandit，优先探索"高收入潜力"的增强方向；冷启动第一单仍不能假设该信号已知。

代码中 1 已实现 IR-aware 网格/MILP 评估修正；2 已实现有限场景鲁棒目标，并扩展到精确 Markov 收入；3 已实现成本感知 Markov 网格优化，可在多个搜索成本场景上取最坏情况；4 已实现价格信号引导的 Data-Bandit 变体。后续工作转向理论推导、大规模对比实验和真实价格信号构造。

当前贡献：在不改变“按性能提升定价”主线的前提下，把“强制购买、先验已知、成本忽略、发现定价割裂”四个理想化边界变成可运行、可测试、可复现实验。结果和限制见 `docs/improvement_results.md`。
