# 论文讲解与复现导航

本文档面向第一次阅读《Optimal Pricing for Data-Augmented AutoML Marketplaces》的读者。目标不是逐行翻译论文，而是回答四个问题：市场究竟在做什么，买家为什么会停止，平台怎样定价，三个实验问题分别验证了什么。

## 1. 一句话理解论文

买家带着一个小数据集进入平台。平台不断尝试“外部数据增强 + 机器学习模型”的组合，模型性能随搜索逐步改善。论文的关键转变是：平台不按外部数据表数量、数据体量或 AutoML 计算成本收费，而是事先公布“性能提升达到多少就收多少钱”的价格曲线；买家每轮都可以继续搜索或停止，并从已发现的模型里购买净效用最高的一个。论文研究如何对这种工具价值定价、如何从停止时间反推买家类型分布，以及如何用较少训练找到好的增强和模型。

这不是传统的“卖一张数据表”。平台卖的是数据增强后得到的模型性能提升，而且搜索过程本身是序贯、随机且有成本的。

## 2. 市场流程和符号

一次交易可以按下面的顺序理解：

1. 平台公布价格曲线 `x(q)`。质量状态 `q` 可以是离散化后的准确率、AUC、损失改善，或相对买家基线模型的性能提升。
2. 买家类型 `θ` 决定其估值曲线 `v^θ(q)`。同一个准确率，不同买家的业务价值不同。
3. 发现引擎每轮训练一个“增强 + 模型”组合，产生质量序列 `Q_1,...,Q_T`。
4. 买家观察当前结果，在“现在停止”和“继续等待”之间选择。
5. 停止后，买家选择已发现模型中 `v^θ(q)-x(q)` 最大的一个，并支付相应价格。

论文用先验 `μ(θ)` 表示市场中各类买家的比例，用转移矩阵 `P^t(q'|q)` 描述当前质量为 `q` 时下一轮出现 `q'` 的概率。

如果买家在第 `τ` 轮购买质量 `q`，其效用为

```text
v^θ(q) - x(q) - c τ,
```

其中 `c` 是每轮真实搜索成本。价格是平台收入；搜索成本影响买家的停止决策，但不等同于卖家的模型价格收入。

## 3. Proposition 4.1：为什么最优停止可以做动态规划

### 3.1 状态为什么需要两个质量

买家停止时，不一定购买“当前轮”的模型，而是购买历史上净效用最高的模型。因此状态要记录：

- `q_best`：历史上使 `v^θ(q)-x(q)` 最大的质量；
- `q_current`：当前轮质量，它决定下一轮的转移分布；
- `t`：当前轮次。

历史轨迹的其他信息都可以丢掉。未来只通过 `q_current` 受过去影响，而停止收益只需要 `q_best`。这正是动态规划成立的充分统计量。

### 3.2 Bellman 递推

在状态 `(q_best,q_current,t)`，买家比较两项：

```text
立即停止：v^θ(q_best) - x(q_best) - c t

继续搜索：对 q_next ~ P^t(.|q_current) 求
          下一状态最优价值的期望
```

下一状态中的历史最优质量，是 `q_best` 和 `q_next` 中净价值更高的那个。终点 `T` 不能再继续，因此边界条件就是立即停止。

代码对应：

- `src/automl_market/market.py::optimal_stopping_dp`
- `src/automl_market/market.py::stopping_time_for_trajectory`
- `src/automl_market/market.py::expected_payment_dp`

论文把复杂度写为 `O(|Q|^2 T)`。直观上，DP 表有 `|Q|^2 T` 个状态；实现中为了清楚核对转移期望保留了显式的下一状态循环。

### 3.3 最容易混淆的地方

`q_best` 不是数值最大的质量，而是“估值减价格”最大的质量。价格曲线不单调时，更高性能未必给买家更高净效用。

## 4. Theorem 4.2：平台怎样从样本轨迹学价格

当论文假设发现成本 `cτ` 相对估值和价格可忽略时，停止时刻不再重要。一条轨迹只需要压缩成“本次搜索发现过哪些质量”的集合 `s`。类型 `θ` 的买家会选择

```text
q*(θ,x,s) ∈ argmax_{q in s} [v^θ(q)-x(q)].
```

给定 `m` 条样本轨迹，平台最大化平均支付：

```text
sum_θ μ(θ) * (1/m) * sum_s x(q*(θ,x,s)).
```

这是一个双层问题：外层选价格，内层买家根据价格选择质量。论文把买家选择嵌入 MILP。

### 4.1 MILP 四类变量

- `x(q)`：每个质量的价格；
- `a(θ,s)`：类型 `θ` 在集合 `s` 中能获得的最大净效用；
- `z(θ,s,q)`：二元变量，等于 1 表示选择质量 `q`；
- `y(θ,s,q)`：支付变量，用来线性化乘积 `x(q)z(θ,s,q)`。

选择约束让 `z=1` 的质量满足

```text
a(θ,s) = v^θ(q)-x(q),
```

其余可选质量只要求净效用不超过 `a`。支付线性化使用

```text
y <= x,
y <= M z,
y >= x - M(1-z),
y >= 0.
```

于是 `z=0` 时 `y=0`，`z=1` 时 `y=x`。目标函数直接最大化所有 `y` 的先验加权平均。

代码对应：`src/automl_market/milp.py::solve_pricing_milp`。

### 4.2 Theorem 4.2 的证明骨架

证明可以分成两层：

1. 有限样本层：证明上述 MILP 恰好编码了样本中买家的最优选择和支付，因此求得经验收入最大化价格。
2. 泛化层：假设估值和收入被常数 `b` 有界，用 Hoeffding 不等式控制经验平均收入与总体期望收入的误差，再比较“经验最优价格”和“总体最优价格”。

论文给出的样本量是 `m = b² log(2/δ)/(2ε²)`，得到加性 `ε` 的 PAC 风格保证。核心意义是：平台不必先精确估计完整马尔可夫模型，也可以直接从发现轨迹学习价格。

### 4.3 复现时必须说明的两个技术边界

第一，论文式约束要求每个 `(θ,s)` 都满足 `sum_q z=1`，也就是即使所有净效用为负，买家仍必须买一个模型。这和正文“买家可以不购买”的自然语义不一致。本项目同时报告：

- `forced-choice revenue`：严格按论文式强制选择计算；
- `realized revenue`：加入零价值、零价格的不购买选项后，真实可实现的收入。

第二，若强制购买模型只约束 `x(q)>=0` 而没有有限价格上界，则把所有价格同时增加一个常数不会改变质量之间的选择，却会持续增加收入，问题会无界。当前 HiGHS 复现明确加入有限上界。对 IR 版本，逐质量最大估值是安全上界；对强制购买版本，这是为了使复现问题良定义而加入的建模假设。

此外，把每个价格限制在“该质量的观测估值集合”上只是透明的有限网格基线，并非一般多质量连续定价的精确算法。不同质量之间的无差异超平面可能在非观测估值处产生更优解。

## 5. Algorithm 1：怎样只看停止时间学习买家先验

平台看不到买家的真实类型，但能观察其在价格 `x^(t)` 下第几轮停止。若平台知道每种类型的停止时间似然

```text
Pr(y | θ_i, x^(t)),
```

就可以先做一次 Bayes 更新得到后验 `w^(t)`，再用学习率平滑：

```text
μ^(t+1) = (1-η_t) μ^(t) + η_t w^(t).
```

代码对应：`src/automl_market/learning.py::smoothed_bayesian_learning`。

关键假设是可识别性：不同类型必须产生不同的停止时间分布。如果两类买家在所有价格下的停止行为几乎相同，仅凭停止时间就无法区分它们。复现实验显式构造了彼此分离的停止分布，并比较论文使用的三类学习率：`1/(t+1)`、`1/sqrt(t)` 和常数 `1/2`。

## 6. Theorem 5.1 与 5.2：学习误差怎样影响收入

Theorem 5.1 说明，在可识别条件下，重复观测能够把估计先验推向真实先验。理解时应把它看成“统计辨识 + 平滑更新”的结果，而不是所有市场环境下自动成立的结论。

Theorem 5.2 定义估计误差代价 CEE：平台用估计的 `(μ,P)` 设计价格，但收入在真实的 `(μ*,P*)` 下实现，二者与真正最优价格的收入差就是 CEE。若先验和转移矩阵的二范数误差都不超过 `ε`，论文证明 `CEE=O(ε)`。

证明直觉是：

1. 先验误差只改变不同买家类型收入的加权，收入有界时这是 Lipschitz 的；
2. 转移矩阵误差会改变未来状态分布，经过有限时域 DP 逐层传播，误差至多按时域和价值上界线性累积；
3. 把“真实最优价格”和“估计模型最优价格”分别代入，再用三角不等式得到最终界。

本项目已经实现精确 Markov 收入评估器，作为该定理后续消融的基础；按当前课程重点，不继续扩展转移误差优化实验。

## 7. Algorithm 2：Data-Bandit 为什么能少训练模型

暴力方法需要对大量增强候选和全部模型逐一训练。论文将每个模型看作一只 Exp3 臂：每轮增强发现模块提出一个候选增强，只从当前概率分布抽取一个模型训练，再用重要性加权奖励更新模型权重。搜索结束后，对最有希望的增强再选择最佳模型。

因此它节省的是“每轮给同一个增强训练所有模型”的开销。论文 RQ1 比较其发现质量和训练效率。

代码对应：

- `src/automl_market/discovery.py`
- `scripts/run_rq1.py`

## 8. 三个研究问题怎样复现

### RQ1：能否高效发现增强和模型

原文使用约 69K NYC Open Data 数据池、Metam 和多种 AutoML 系统，但原始任务和完整实现未公开。本项目用 UCI Wine Quality 构造可公开复现的连接任务，比较：

- Data-Bandit：Algorithm 2 风格，每轮只训练一个抽样模型；
- Data-All：每个候选增强训练所有模型，作为完整预算参照；
- Data-Alt：轮换模型的低成本基线；
- AutoML：不加入外部增强。

60 个重复任务的结论是：Data-Bandit 的发现曲线 AUC 显著高于 Data-All，达到 95% oracle 增益所需训练次数减少 27.5%--30.3%；但完整 60 次预算终点仍是 Data-All 最好。Data-Bandit 与 Data-Alt 的配对区间跨 0，只能说表现相当，不能声称显著更优。

### RQ2：不同定价方法的收入如何

缩减设置使用 10 个随机任务、4 个质量、6 个买家类型。比较论文 MILP、Independent、Shift、Jiggle，以及使用 OOS 轨迹训练的参考 MILP。

在论文的强制购买指标下，IS MILP 的归一化收入为 `0.7926±0.0098`，高于基线，定性接近原文 Figure 4 所示约 85% 福利捕获。Shift 不劣于 Independent，Jiggle 不劣于 Shift，符合 Appendix D.1 的设计。

加入自愿购买后，Independent 在本缩减设置中的 OOS 实现收入最高 (`0.5468±0.0119`)，而强制购买 MILP 只有 `0.4075±0.0138`。这不是说 Independent 普遍最优，而是说明“优化强制支付”不等于“优化真实可收收入”。

### RQ3：先验学习速度和稳定性如何

复现覆盖 5 种真实先验、3 种学习率、批量 10/100、5 个随机种子和 1000 轮。随机先验、批量 100 时，最终 KL 为：

- `1/(t+1)`：`0.12083±0.00371`；
- `1/sqrt(t)`：`0.01926±0.00139`；
- `1/2`：`0.00495±0.00169`。

常数 `1/2` 收敛快但尾部波动最大；批量 10 时尤其不稳定。`1/sqrt(t)` 在速度和稳定性之间更均衡，与论文的定性观察一致。
